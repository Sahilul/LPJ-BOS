Cara menghubungkan

Alamat server: {{.url}}. Kirim token di header Authorization: Bearer …. Contoh konfigurasi (VS Code .vscode/mcp.json memakai kunci servers, Claude/Cursor memakai mcpServers):

Claude.ai / Claude Desktop (Tambahkan konektor kustom)

  1. URL server: {{.url}}
  2. Autentikasi: pilih Tanpa masuk (bukan OAuth).
  3. Header permintaan, pilih salah satu:
    • Nama X-API-Token, nilai token saja (tanpa kata “Bearer”), atau
    • Nama Authorization, nilai Bearer <token> (ada kata Bearer + spasi).
  4. Centang Wajib, lalu Tambahkan.

Header lain seperti X-Auth-Token atau X-Access-Token tidak dikenali dan akan ditolak (401).

ChatGPT (konektor kustom)

ChatGPT belum bisa mengirim header kustom, jadi token ditaruh di alamat server. Butuh paket Plus/Pro/Business dan domain HTTPS publik (localhost tidak bisa).

  1. Di ChatGPT: Settings → Apps & Connectors → Advanced, nyalakan Developer mode.
  2. Create connector: nama LPJ BOS, MCP Server URL: 
    {{.urlChatgpt}}
  3. Authentication: No authentication. Centang I trust this application, lalu Create.
  4. Di percakapan baru, klik + → Developer mode → pilih LPJ BOS, lalu minta mis. “Tampilkan BKU bulan ini”.

Alamat di atas memuat token rahasia — jangan dibagikan. Untuk mencatat/menghapus data pakai token Baca & tulis; ChatGPT akan meminta konfirmasi sebelum menjalankan aksi tulis.
